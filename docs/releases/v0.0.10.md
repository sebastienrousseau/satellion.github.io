## Highlights ⭐️

* **Built against passmcp 0.0.10**: the site's check count (`139` checks across nine phases), sample report readout, and 15-component family table come from `passmcp` `0.0.10`, and every Go module page pins `v0.0.10`.
* **Go module resolution for `satellion.com/passmcp-sdk-go`**: `/passmcp-sdk-go/` publishes `go-import` and `go-source` tags and is checked on every build by `scripts/modules.py` and `scripts/footer_links.py`.
* **15-component family table**: `_layouts/family.html` and `README.md` list all six Apache-2.0 MCP language SDK satellites (`passmcp-sdk-go`, `passmcp-sdk-python`, `passmcp-sdk-java`, `passmcp-sdk-cpp`, `passmcp-sdk-typescript`, and `passmcp-sdk-rust`) alongside the nine existing components.
