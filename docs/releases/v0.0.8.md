## Highlights ⭐️

* **Built against passmcp 0.0.8**: the numbers, the sample report and the family table come from the 0.0.8 release, and every module page pins 0.0.8.
* **Live passmcp-graph demo built by SSG**: `/passmcp-graph/demo/` renders passmcp-graph's share-safe JSON export with SSG 0.0.68 under the site's Content-Security-Policy.
* **Strict single-origin Content-Security-Policy**: every built page and sample report is checked by `scripts/strict_csp.py` to ensure zero inline scripts, inline styles, or third-party assets.
* **Fuzzing, ruff, and footer verification**: `scripts/fuzz_family.py` fuzzes the family manifest parser, `make ruff` lints and formats build scripts, and `scripts/footer_links.py` verifies every page links its own project and licence.
