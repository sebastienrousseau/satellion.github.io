## Highlights ⭐️

* **Built against passmcp 0.0.7**: the numbers, the sample report and the family table come from the 0.0.7 release, and every module page pins 0.0.7.
* **A live passmcp-graph demo**: passmcp's page shows passmcp-graph's dashboard, and `/passmcp-graph/demo/` serves the page itself, rendered share-safe from passmcp-graph's published fixture at its latest release.
* **Every package described as it ships**: the module pages and passmcp's page were checked claim by claim against each repository at v0.0.7.
* **In lockstep with passmcp 0.0.7**: 0.0.5 was never tagged, so its changes ship here, at the family's version.
