# Contributing

Thank you for helping. The site states facts about
[passmcp](https://github.com/sebastienrousseau/passmcp), so every change is held
to one rule: **a claim on the page must be backed by passmcp's source, its
output, or a cited public source.**

- Numbers from a passmcp run (score, grade, counts, ledger, phases, evidence)
  are generated by `make data` from passmcp's sample report. Never type them.
- A statistic about the market needs a link to where it was published.
- A status is concrete: "Released in 0.0.1" linking that release, or "Not
  yet released" linking the issue or changelog entry that tracks it.

## Build

```sh
make check     # every gate that needs no passmcp release
make site      # needs Go, Python 3.12+ and ssg 0.0.68 (cargo install ssg --locked --version 0.0.68)
make serve     # then open http://localhost:8000
```

[DEVELOPMENT.md](DEVELOPMENT.md) maps every CI gate to its local command.
Add an entry to [CHANGELOG.md](CHANGELOG.md) under the version being prepared.

## Commits

Conventional Commits, signed, with a DCO `Signed-off-by` trailer.
