# Working on satellion.com as an AI agent

satellion.com is the public site of Satellion and of passmcp, built from
this repository with SSG. It also serves the pages Go reads to resolve the
family's `satellion.com/...` module paths, and the attestation and graph
format URIs. Its value is that every claim on it can be checked.

Read [DEVELOPMENT.md](DEVELOPMENT.md) first for the toolchain and the local
equivalent of every CI gate. This file is only the constraints.

## Hard gates

| Gate | Command |
|---|---|
| Everything that needs no passmcp release | `make check` |
| Tests, and coverage at 85% or more | `make test`, `make coverage` |
| Complexity: cyclomatic 10, cognitive 15 | `make complexity` |
| Every version reference agrees | `make verify-versions` |
| The core pages build with SSG 0.0.68, SSG's quality gate at every pillar and no accessibility issue | `make core` |
| README follows the portfolio template | `make readme-check` |
| No retired product name | `make name-guard` |

## Commits

- Every commit is signed and carries a DCO `Signed-off-by` trailer, which
  only the human adds. An agent's shell usually cannot reach the
  maintainer's ssh-agent; hand commits over as a script.
- Conventional Commits for the subject line.
- Never rewrite published history.

## Things that are load-bearing

- **A claim needs evidence.** Numbers from a passmcp run are generated by
  `make data`, never typed. A market statistic links to its source. A
  status is concrete: "Released in 0.0.1" linking the release, or "Not yet
  released" linking the issue or changelog entry. Never "Planned",
  "Shipping" or "Available".
- **The Go module pages are infrastructure.** Removing or renaming one, or
  changing its `go_import`, breaks `go install` for every user. A new Go
  module in the family needs its page and its `scripts/modules.py` entry
  in the same change.
- **The stable URLs stay put.** The paths listed under "Stability
  guarantees" in the README are resolved by other systems.
- **The site is static.** No cookies, analytics, forms that post, or
  third-party scripts ([ADR 0003](docs/adr/0003-static-site-not-the-application.md)).
- **security.txt expires.** The build fails 30 days before; renew it by
  moving `security_expires` in `content/index.md` on.

## Things that look like bugs and are not

- **`dist/` and `.build/` are not in the tree.** They are build output.
- **`_layouts/family.html` is generated.** `make family` renders it from
  passmcp's `ecosystem.json`; change the manifest in passmcp, not the file.
- **`_layouts/` and `graph-demo/_layouts/` are MIT, the rest
  GPL-3.0-only.** The layouts are vendored from the SSG theme suite;
  `REUSE.toml` records it. `_layouts/csp.html`, the site's one
  Content-Security-Policy, is the site's own.
- **`/highlight.css` is copied from a fingerprinted file.** SSG 0.0.68 links
  the plain name; the Makefile says why.
- **The ecosystem table says every component is at 0.0.4.** That is the
  family's lockstep version, stated identically in every repository.

## Scope

- Do not couple a copy or layout cleanup to a build change.
- Do not add a Python dependency outside `scripts/requirements.in`, and
  regenerate the hash-locked `scripts/requirements.txt` when you do.
